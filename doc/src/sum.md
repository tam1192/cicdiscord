# 概要
簡単なyaml定義ファイルと、github actions等ci/cdを組み合わせてチャンネルを管理するbotツール

## 課題
- 標準だとまとめて設定を適用できないのが大変
- ロールの設定が多すぎて、チェック入れ忘れとかが怖い
- チャンネルごとの権限設定の見落としが怖い
- 設定のテンプレート化が難しい
- 権限設定を一つ一つ確認し合わないといけないから、複数管理者での運用が難しい

## 解決策
- 複数のチャンネルに同じ権限設定が流せるようにする
- 必要な権限のみを記入し、設定が見やすいようにする
- yamlファイルで管理し、テンプレート化できるようにする

## ci/cdiscord　のメリット
- yamlファイルなのでgitで管理可能
- gitのci/cd機能を用いて、自動的に設定を反映させることが可能
